# 1) Design goals

* Calm, professional UI with **teal as the only brand hue**, supported by neutral grays and clean whites.
* Strong legibility on both light/dark backgrounds.
* Minimal extra colors: use semantic hues only for **success / warning / error / info**.

---

# 3) Color roles & when to use them

## Light mode

* **Page background:** N-025
* **Default surface (cards, panels, modals):** N-000
* **Primary text (headings, body):** N-950
* **Secondary/muted text:** N-600
* **Disabled text:** N-300
* **Borders/dividers:** N-100 (1px)
* **Interactive focus:** 2-layer ring — inner N-000 (2px) + outer P-600 (2px).
* **Primary button:** bg P-600 → hover P-700 → pressed P-800; text **N-000**
* **Quiet button / ghost:** text P-600; hover bg P-050; pressed bg P-100
* **Links:** text **P-600** (visited P-700); underline only on hover for dense UIs.

## Dark mode

* **App background:** N-950
* **Surfaces:**

  * S-0: N-950 (base)
  * S-1: N-900
  * S-2: N-800
* **Primary text:** N-025 / N-000
* **Secondary/muted text:** N-600
* **Borders:** N-800
* **Primary button:** same teal steps (P-600/700/800) with **N-000** text
* **Focus:** 2-layer ring — inner N-950 (2px) + outer P-400 (2px) for 3:1 against dark.

## States (generic)

* **Hover:** darken bg by one step (e.g., 600→700) or add P-050 overlay at 8% (light mode).
* **Pressed:** darken two steps (e.g., 600→800).
* **Disabled:** reduce contrast via opacity 38% on control + keep text N-300/N-600 (never drop below 3:1 for iconography).

# 4) Typography blueprint (font + color)

## Font family

* **Sans UI:** `Inter` (Variable if available). Fallback stack: *Inter, "SF Pro Text", "Segoe UI", Roboto, Arial, sans-serif*.
* **Mono (code/figures):** *JetBrains Mono, Menlo, Consolas, monospace*.

## Type scale (rem based on 16px root)

* **Display-lg:** 3.0rem / 1.1 / 700
* **Display-md:** 2.25rem / 1.2 / 700
* **H1:** 1.875rem / 1.25 / 700
* **H2:** 1.5rem / 1.3 / 600
* **H3:** 1.25rem / 1.35 / 600
* **Body-lg:** 1.125rem / 1.6 / 400–500
* **Body:** 1.0rem / 1.6 / 400–500 *(default)*
* **Caption:** 0.875rem / 1.5 / 500
* **Micro:** 0.75rem / 1.4 / 600 (all-caps, +0.02em tracking)

## Type colors (pair with the modes above)

* **Headings / Body:** N-950 (light) / N-000 (dark)
* **Muted / Helper:** N-600
* **Links:** P-600 normal → P-700 hover/visited
* **On-brand (text placed over teal surfaces):** **N-000** on P-600+ only; for **P-500** use **N-950** text or bump size/weight to meet AA-Large.

# 5) Components quick rules

* **Inputs (light mode):**

  * bg N-000, border N-200 (rest) → P-600 (focus), shadow 0 0 0 4px P-050 (optional halo).
  * Placeholder text N-600 at \~70% opacity.

* **Cards:**

  * Light: bg N-000, border N-100.
  * Dark: bg N-900, border N-800.
  * Emphasis card: subtle top bar P-600 at 2–4px or a 2% P-050 fill (light).

* **Badges/Tags:**

  * Primary: bg P-050, text P-700, no border.
  * Semantic: use the relevant hue at 100/050 like **Success** bg `#E9F7EE` with text `#166534`.

* **Overlays/Scrims:**

  * Light: N-950 @ 45–55%
  * Dark: N-950 @ 60–70%

---

# 6) Accessibility guardrails (WCAG 2.1 AA)

* Body text needs **≥ 4.5:1** contrast against its background.
* Large text (≥ 18pt regular or 14pt bold) can use **≥ 3.0:1**.
* **P-600** is your safe brand bg with white text; **P-500** requires dark text or larger/bold labels.
* Focus indicators should achieve **≥ 3:1** against the surrounding pixels (use the 2-layer focus recipe above).

---

# 7) Implementation checklist (HOW-TO)

1. **Define tokens** in your system (whatever format you use) for the color roles above (e.g., `color.bg.page`, `color.text.primary`, `color.brand.600`, etc.).
2. **Map UI components** to those roles rather than hard-coding hex.
3. **Add state tokens** (hover/active/disabled/focus) using the step changes provided.
4. **Set light/dark themes** by swapping only the role tokens (neutrals change; teal stays).
5. **Validate contrast** for any new combination with a checker; treat **P-600** as the default brand bg, **P-500** for outlines/links/badges.
